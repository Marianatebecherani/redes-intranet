# Frontend

Interface web da intranet.

> **Estado atual:** ainda não implementado. Esta seção descreve o que está planejado; comandos de instalação, desenvolvimento e build serão adicionados junto com o código.

## Tecnologias planejadas

- React com Vite.
- Build estático servido pelo [backend](../backend/README.md) na mesma imagem Docker.

## Telas planejadas

- Login.
- Mural de comunicados.
- Diretório de colaboradores.
- Explorador de arquivos das pastas compartilhadas, conforme as permissões do usuário.
- Editor de imagens PNG em formato redondo, com prévia, download e envio para uma pasta compartilhada.
- Gestão de usuários, disponível apenas para administradores.
- Indicação da instância da aplicação que atendeu a requisição.
